# FreeLingo independent frontend

Use pnpm exclusively. Work on task branches from local development and merge locally after checks. Never push, publish or deploy without explicit authorization.

TanStack Start owns presentation and same-origin transport; FastAPI owns authorization and business rules. Keep access tokens in browser memory and refresh tokens in httpOnly cookies. Preserve isolated learning state per target language and en-GB as the default.

Preserve the existing fl-* visual tokens, Geist fonts, CJK rendering, monochrome controls, themes and URLs. Code uses strict TypeScript, no explicit any, single quotes, no semicolons and two spaces. Include relevant tests and docs with each change.

Do not commit credentials, session data or user audio. Runtime/device/deployment acceptance must be supported by actual validation.
